# 市场交易时间与规则校验 Skill

## 1. 品种交易时间规则 (北京时间)

| 市场类别 | 阶段 | 时间段 (北京时间) |
| :--- | :--- | :--- |
| **A 股** | 上午盘 / 下午盘 | **09:30 - 11:30** / **13:00 - 15:00** |
| **港股** | 上午盘 / 下午盘 | **09:30 - 12:00** / **13:00 - 16:00** |
| **美股 / QDII美股基金** | 常规盘 (夏令时) | **21:30 - 04:00 (次日)** |
| **美股 / QDII美股基金** | 常规盘 (冬令时) | **22:30 - 05:00 (次日)** |

## 2. QDII 基金识别引擎规则

包含 `QDII`、`纳斯达克`、`标普`、`美股`、`美国`、`全球`、`海外`、`互联`、`科技`、`芯片`、`软件`、`人工智能/AI` 等关键字且不含 `港股/恒生` 的基金，自动识别为 **`us` (美股市场)**。

## 3. Commit 强制校验机制

任何代码修改触发 `git commit` 时，必须自动运行：

```bash
node scripts/verify-market-time.cjs
```

若校验失败，必须阻断 commit，并明确指出时间算法或市场匹配规则中的失败原因。
